## 🌍 Overview
**Budget Buddy** is a web-based showcase for an app concept aimed at promoting **financial literacy and smart budgeting**, especially for **low-income individuals and families**.

This project supports **SDG 1: No Poverty** by encouraging better money management through intuitive tools and education.

It’s built using **HTML5**, **CSS3**, and **JavaScript**, designed to be **responsive**, **interactive**, and **ready for deployment**.

---

## 🎯 Purpose
The goal of this site is to introduce users to **Budget Buddy’s mission**, **features**, and **impact**, while demonstrating modern web development techniques using HTML, CSS, and JS.
